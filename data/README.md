# Data folder

This folder contains Health360's data dictionary and quality-audit outputs.

The root-level `smart_healthcare_dataset.csv` is the supplied synthetic source file (5,000 records, 16 original fields). The prepared Tableau-ready export has 27 fields after adding 11 grouping/display fields. See `DATA_QUALITY_REPORT.md` for findings and limitations.

The project owner identifies the dataset as synthetic. Its original publisher/licence is not documented in the supplied materials. Do not present the fields as verified clinical measurements or use them for diagnosis or treatment.
