# Data folder

This folder contains documentation outputs from the Health360 data-preparation process. The row-level CSV is intentionally excluded from the public repository pending confirmation of source provenance, licence and redistribution permission.

The source file contains 5,000 records and 16 columns. The Tableau-ready export has 27 fields after adding 11 grouping/display fields. See DATA_QUALITY_REPORT.md for findings and limitations.
