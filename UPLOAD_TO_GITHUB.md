# Health360 Repository Handoff

Repository: https://github.com/Git-SI-2206/Health360-Healthcare-Analytics

## GitHub Pages
1. Open repository Settings → Pages.
2. Select Deploy from a branch.
3. Choose branch main and folder /(root), then Save.
4. Open the Pages URL GitHub displays and test the site, Dashboard embed and Story embed.

## Tableau Public
- Dashboard: https://public.tableau.com/views/Health360_Clinical_Healthcare_Risk_Analysis/Health360_Dashboard_Final_
- Story: https://public.tableau.com/views/Health360_Clinical_Healthcare_Risk_Analysis/Health360_Patient_Risk_Lifestyle_Insights

## Flask
GitHub Pages serves static files only and does not execute Python. Deploy Flask separately to a Python-capable host if required by the assessment.

The row-level CSV and packaged Tableau workbook are excluded by default. Add them only after reviewing workbook contents and confirming the data can be redistributed.
